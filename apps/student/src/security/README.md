# NSG BRO Security Foundation

The security layer now exposes a deterministic watermark placement model that viewers can render over protected PDF/video surfaces. It carries app label, student identity and privacy-masked mobile data.

Viewer integration should render the returned watermark above content and refresh placement periodically. Native Android secure-window flags and recording protection belong to the UI/native layer and remain best-effort because device behavior varies.

Server-side authorization, encrypted offline storage, signed/expiring content URLs and device policy remain required for production protection.
