# NSG BRO — M11 Premium UI Verification Contract

M11 premium UI is an implementation contract, not only a planning note.

## Required implementation markers
- StudyBro: premium design tokens, visual hierarchy, dashboard surfaces, progress/streak/quick actions, refined navigation/resource states, motion states, loading/empty/offline/error states, dark-mode support.
- Admin NSG: professional phone-first design tokens, dashboard/navigation, content/student/announcement/live-control/analytics surfaces, feedback states and security-focused interactions.
- Shared quality: accessible touch targets, consistent spacing/typography, performant animations, reduced-motion consideration, no web admin panel.

## Acceptance
V2 must verify both app implementations and their UI contracts without removing existing functionality.
